## 🤖 Machine Learning

The ML pipeline processes earthquake and geographic features to estimate tsunami-generation risk.

### Input Features

```text
Magnitude
Depth
Latitude
Longitude
Geographic Context
Historical Context
```

Additional features are used only when supported by validated data.

### Models

The project evaluates classification approaches such as:

- Logistic Regression
- Random Forest
- Gradient Boosting

### Evaluation

Because tsunami-related events can be highly imbalanced, model evaluation considers:

- Precision
- Recall
- F1-Score
- ROC-AUC
- PR-AUC

> Accuracy is not used as the only evaluation metric.

---

## ✨ Gemini AI Analyst

Gemini is used as an **explanation layer**, not as the prediction engine.

```text
ML Model
   ↓
Structured Risk Assessment
   ↓
Gemini
   ↓
Human-Readable Explanation
```

### Gemini Explains

- Why the model produced the assessment
- Important contributing factors
- Risk interpretation
- Uncertainty
- Recommended verification

### Gemini Does Not

- Calculate the primary risk score
- Override the ML model
- Invent scientific measurements
- Invent observations
- Generate official warnings

---

## 🔌 Prediction API

The frontend sends earthquake information to the prediction service:

```json
{
  "magnitude": 0,
  "depth_km": 0,
  "latitude": 0,
  "longitude": 0
}
```

The API returns the structured risk assessment generated by the ML pipeline.

---

## 📊 Risk Assessment

The application presents model output using application-level categories:

```text
LOW
MODERATE
HIGH
CRITICAL
```

> These categories are **application-level interpretation categories** and are not official tsunami-warning thresholds.

The application clearly separates:

```text
MODEL ASSESSMENT
```

from:

```text
OFFICIAL WARNING
```

## 🌐 Data Sources

The project is designed around authoritative public sources, including:

- **USGS** — Earthquake data
- **NOAA / NCEI** — Historical tsunami information

Data is validated and processed before entering the ML pipeline.


---

## 🎯 Core Design Principle

> **The ML model predicts. The API connects. The map provides geographic context. Gemini explains.**

This separation keeps the system modular, explainable, and easier to maintain.

---

## ⚠️ Limitations

Tsunami generation is a complex physical process and cannot be completely represented by a small set of machine-learning features.

Therefore:

- Model outputs are estimates
- Historical relationships do not guarantee future behavior
- Data quality affects model performance
- The system does not replace physical tsunami forecasting
- The system does not replace official warning agencies
